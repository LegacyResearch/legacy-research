
# Modelo de Pesquisa — Legacy Research

Este diretório define a estrutura padrão das pesquisas da Legacy Research.

Cada pesquisa deve possuir documentação própria, dados utilizados, gráficos, códigos, fontes e histórico de atualizações.

## Estrutura da pesquisa

- README.md: apresentação e índice da pesquisa.
- tese.md: documento principal da pesquisa.
- Dados/: bases utilizadas.
- Graficos/: visualizações e gráficos.
- Codigos/: scripts e cálculos.
- Fontes.md: referências e fontes de dados.
- Atualizacoes/: acompanhamento de novas informações.
- Avaliacao.md: avaliação dos resultados e da tese.

## Princípios

1. Transparência na utilização dos dados.
2. Rastreabilidade das fontes.
3. Reprodutibilidade dos resultados.
4. Preservação das hipóteses originais.
5. Registro de erros e revisões.
